Before running the program, make sure to check which port the board is connected to and make the change to port number in the python script.

Program the board using the "out_with_sig_kpub.bin file using STM32 Cube programmer. 

after running the python script, press the reset button on the board and type "start" in the terminal to start communication

After this step, type "plate" and "secret" followed by enter to get car plate details as well as the secret message.
